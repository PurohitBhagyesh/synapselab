01 What is an Artificial Neuron & Synapse?

An artificial neuron is inspired by biological brain cells. It receives one or more numeric inputs ($x_1, x_2$), multiplies each input by a learnable strength called a Weight ($w_1, w_2$), adds an adjustable baseline called a Bias ($b$), and passes the result through an Activation Function ($f$).

Formula:   z = (w₁ · x₁) + (w₂ · x₂) + b   |   Output = f(z)

02 Activation Functions: Why We Need Non-Linearity

Without activation functions, even a network with 100 hidden layers is mathematically identical to a single linear equation ($y = mx + b$). Non-linear activation functions allow neural networks to bend, curve, and approximate complex real-world patterns like curves, images, and language.

ReLU (Most Popular):
$f(z) = \max(0, z)$
Fast computation, avoids vanishing gradients.
Sigmoid:
$f(z) = \frac{1}{1 + e^{-z}}$
Squashes outputs smoothly between 0 and 1.
Tanh:
$f(z) = \tanh(z)$
Zero-centered, squashes between -1 and +1.

04 Backpropagation & Gradient Descent: How It Learns

How does a neural network actually get smarter?
1. Forward Pass: It makes a prediction ($\hat{y}$).
2. Loss Calculation: It calculates how far off it was using Mean Squared Error: $\text{Loss} = (y - \hat{y})^2$.
3. Backpropagation: Using calculus (the chain rule), it calculates which weights caused the mistake.
4. Weight Update: It nudges every weight in the opposite direction of the slope to decrease the loss:

Update Rule:   W := W - (learning_rate · ∂Loss/∂W)
