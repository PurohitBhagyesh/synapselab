# Security Policy

SynapseLab is committed to ensuring student privacy, educational accessibility, and secure software distribution.

---

## Architecture & Privacy Protections

1. **Client-Side Execution**: All neural network computations, 3D math projections, and Python code simulations execute entirely inside the student local web browser. No student code or personal inputs are transmitted to external servers.
2. **Zero Cookies**: The application uses zero HTTP cookies, zero tracking pixels, and zero analytics packages.
3. **No External Runtime CDNs**: All visualizer logic runs from local static assets without external script dependencies.

---
